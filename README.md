# موقع عيادة د. منير الشكري

موقع عربي ثابت متجاوب وجاهز للنشر على GitHub Pages.

## النشر
1. فك ضغط الملف وارفع **محتويات** المجلد إلى جذر مستودع GitHub.
2. من Settings → Pages اختر Deploy from a branch، ثم main و /root.
3. افتح رابط GitHub Pages بعد النشر.

## لوحة الإدارة
افتح `admin.html` لتحرير النبذة والخدمات والمقالات والأسئلة. انقر **تنزيل ملف التحديث data.js**، ثم ارفع الملف الجديد إلى المستودع مكان `data.js` وانتظر إعادة النشر. لا توجد مصادقة أو حفظ سحابي؛ أي زائر يعرف رابط لوحة الإدارة يمكنه فتح محرر محلي لكن لا يمكنه تغيير الموقع المنشور دون صلاحية GitHub. لا تستخدم اللوحة لحفظ بيانات المرضى.

## التعديلات الأساسية
- معلومات العنوان والأرقام والدوام موجودة في `index.html`.
- الألوان والخطوط في `style.css`.
- الشعار الأصلي في `assets/logo.jpg`.
- المحتوى القابل للتحرير في `data.js`.

## ملاحظات
- الصور المعروضة هي الشعار المرفق فقط؛ يمكن إضافة صور العيادة بعد الحصول عليها.
- رابط الخرائط يفتح خرائط Google مباشرة، وليس خريطة مضمنة.
- لإضافة حجوزات إلكترونية أو تسجيل دخول حقيقي أو تحرير سحابي، يلزم خادم خلفي ومصادقة وتخزين آمن.
- أنشئ `sitemap.xml` بعد تحديد الدومين النهائي، ثم أرسله إلى Google Search Console.
