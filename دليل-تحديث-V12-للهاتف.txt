عيادة د. منير الشكري — النسخة V12 PRO

تم تجهيز:
1) 35 موضوعًا طبيًا مفصلًا (14 توعويًا عامًا و21 حالة أو فحصًا) مع صور طبية مناسبة حسب القسم، ووصف وأعراض وأسباب ودور الفحوص واحتياطات ومتى يلزم التقييم العاجل ومصادر. الصور أمثلة لأجهزة الفحص وليست صورًا لحالات مرضى، ولا تثبت تشخيصًا. المحتوى مسودة توعوية يجب اعتمادها سريريًا قبل النشر.
2) مجموعات الفحوصات الأربع و46 فحصًا وفق القائمة الرسمية.
3) محرر إدارة للواجهة الرئيسية ومجموعات الفحوص والمقالات. يمكن الترتيب، والإضافة، والنسخ، والحذف، والتعديل، والإخفاء، وتغيير الصورة والمعلومات، والبحث والتصنيف.

كيف تحدّث الموقع من الهاتف:
- احفظ نسخة احتياطية من مستودع GitHub وبيانات الموقع قبل الرفع.
- نزّل ملف V12-PRO-UPDATE-MOBILE.zip وافتحه في مدير الملفات.
- ارفع الملفات إلى جذر مستودع dr-munir-clinic. واختر الاستبدال للملفات بالاسم نفسه.
- لا تحذف ولا تستبدل config.js أو site-data.json أو إعدادات Firebase.
- Commit changes، وانتظر النشر ثم افتح رابط الموقع وصفحة home-editor.html.

التحرير والنشر:
- من home-editor.html رتّب أقسام الواجهة، واكتب نصوصها، وأضف أقسامًا جديدة، وعدّل قوائم الخدمات والمقالات.
- اضغط "حفظ مسودة الهاتف" للاحتفاظ محليًا. هذه الخطوة لا تنشر للزوار.
- من تبويب الحفظ والنشر نزّل 3 ملفات: homepage-layout.json وservices-catalog.json وawareness-content.json.
- ارفع الثلاثة إلى GitHub بالاسم نفسه، ثم Commit changes. التغييرات تظهر لجميع الزوار بعد النشر.
- حمّل نسخة احتياطية قبل الحذف أو التغيير الكبير.

التحكم الموجود وحدوده:
- يمكن إدارة ترتيب وظهور وعنوان ونص أقسام الواجهة، وإنشاء قسم مخصص وإدارة صورته ورابطه ولوني مكونات V12.
- يمكن إدارة وترتيب مجموعات الخدمات وفحوصاتها الأربع والـ46، والنقل بينها؛ جميع القوائم الديناميكية تقرأ services-catalog.json.
- يمكن تحرير موضوعات التوعية ونشرها/إخفاؤها وترتيبها مع صور محلية ونصوص مفصلة.
- لا تزال بعض القوالب الداخلية القديمة وتفاصيل السلايدر والأزرار الثابتة لا تدعم التحرير المباشر؛ ما زالت تحتاج تعديل ملفات القالب.
- هذه لوحة إعداد ونشر من ملفات وليست لوحة إدارة آمنة تعمل مباشرة في Firebase؛ لا يوجد نشر فوري بدون GitHub.
- لا يحوّل إضافة اسم فحص جديد تلقائيًا إلى صفحة HTML مستقلة لذلك الفحص.
