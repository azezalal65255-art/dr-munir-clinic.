تحديث لوحة التحكم V9 — عيادة د. منير الشكري

هذا تحديث تدريجي للوحة التحكم الحالية، وليس نظام CMS شاملًا لكل عنصر في كل صفحة.
ارفع ملفي admin.js و admin.css فقط إلى جذر مستودع GitHub مع استبدال النسختين السابقتين.
لا ترفع ملفات site-data.json أو config.js من نسخ قديمة، ولا تحذف أي ملف آخر.

الجديد:
- رفع أو خفض ترتيب العناصر في القوائم.
- نسخ أي عنصر لإنشاء مسودة مخفية.
- إظهار أو إخفاء العنصر.
- استمرار الإضافة والتعديل والحذف والحفظ والتصدير والنسخ الاحتياطي الموجودة سابقًا.
- أقسام الخدمات والفحوصات والمقالات والمؤتمرات والوظائف والبحوث والفيديوهات والصور والأسئلة الشائعة.

حدود مهمة:
- وضع التحرير المحلي: الحفظ داخل الهاتف فقط؛ لتنشر التعديلات نزّل site-data.json وارفعه إلى GitHub.
- وضع Firebase: الحفظ المباشر يتطلب مشروع Firebase وقواعد أمان وحساب مسؤول مفعّل.
- لا تتحكم اللوحة حاليًا في جميع أجزاء HTML الثابتة والسلايدر والترجمة وتصميم كل صفحة؛ هذه تحتاج إلى نقل الواجهات إلى نظام قوالب ومكونات ديناميكية.
- إضافة فحص بصفحة HTML جديدة ما زالت تتطلب إنشاء ملف HTML مطابق.
- لا تحفظ معلومات المرضى أو الشكاوى الحساسة في بيانات الموقع العامة.
- احفظ نسخة احتياطية قبل التعديلات الكبيرة.
