دليل V3 — إعداد لوحة عيادة د. منير الشكري من هاتف سامسونج

1) حمّل ملف ZIP وفك ضغطه من تطبيق ملفاتي على الهاتف.
2) ارفع كل الملفات الموجودة داخل المجلد إلى جذر مستودع GitHub الحالي، مع استبدال النسخ القديمة ثم Commit changes. لا ترفع ملف ZIP نفسه ولا تضع الملفات داخل مجلد فرعي.
3) افتح رابط: https://azezalal65255-art.github.io/dr-munir-clinic./firebase-setup.html
4) اتبع خطوات مساعد إعداد Firebase خطوة بخطوة: إنشاء مشروع Firebase، تطبيق ويب Web، تفعيل Email/Password وإضافة مستخدم، إنشاء Firestore ونشر قواعد الأمان.
5) الصق كود firebaseConfig العام داخل مساعد الإعداد واضغط تنزيل config.js، ثم ارفع هذا الملف فقط إلى جذر GitHub واستبدل القديم.
6) افتح admin.html وسجّل بالبريد وكلمة المرور التي أنشأتها في Firebase. انسخ UID الذي سيظهر في حالة عدم امتلاكك صلاحية الإدارة، ثم أنشئ في Firestore مجموعة admins ووثيقة Document ID تساوي UID، بحقل active من نوع boolean بقيمة true. عد إلى admin.html وسجّل الدخول.
7) بعد التحقق من القواعد والصلاحيات، اضغط تهيئة المحتوى الافتراضي من داخل لوحة التحكم لأول مرة فقط. المحتوى سيُنشر للزوار عند حفظه مباشرة في Firestore.
8) تفعيل طلبات المواعيد اختياري: من إعدادات الموقع، ويبدأ مغلقًا لأمان المرضى. لا تفعل قبل التأكد من المسؤول ومن جاهزية استقبال الطلبات.
9) يمكنك إضافة صور بدون تفعيل Firebase Storage عبر رفعها كملفات عادية إلى GitHub وإدخال اسم الصورة (مثل doctor.jpg) في لوحة التحكم. رفع الصور مباشرة من اللوحة يتطلب Storage وخطة Firebase Blaze مع فوترة.
10) استخدم زر نسخة احتياطية داخل لوحة التحكم لتنزيل ملف بيانات الموقع دون بيانات حجوزات المرضى.

مهم: ملف firestore.rules يجب نسخ محتواه إلى قسم Rules داخل Firebase ثم Publish. مجرد رفعه إلى GitHub لا يطبّق القواعد. لا تشارك كلمة مرور المسؤول أبدًا، ولا تضف مفاتيح حسابات الخدمة الخاصة إلى GitHub. مفاتيح تهيئة الويب Firebase عامة والحماية الفعلية تأتي من Firebase Authentication وقواعد Firestore.
